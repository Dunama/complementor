# Complementor

Complementor is a fun web app that generates a unique compliment for each letter of your name, complete with matching emojis and a beautiful animated background. The app is built with Flask and features a modern, mobile-friendly UI with a snow animation and typewriter effect.

## Features

- **Compliment Generator:** Enter your name and receive a personalized compliment for each letter.
- **Emoji Matching:** Each compliment is paired with a unique emoji.
- **Animated UI:** Includes a snow animation background and typewriter effect for a delightful user experience.
- **Mobile Responsive:** Fully responsive design for all devices.
- **Download Result:** Download your compliment card as an image (works on desktop and mobile).
- **No Repeats:** Compliments and emojis do not repeat for the same letter in a name.
